
## 📝 Descrição das Pastas

### 1. `DOC_ATIVIDADES/`

Pasta reservada para armazenar apostilas, slides, enunciados de trabalhos e demais documentos de referência enviados pelo docente ao longo da disciplina.

### 2. `ATIVIDADES_ENTREGUES/`

Pasta destinada à entrega e organização dos códigos-fonte desenvolvidos em linguagem C. Abaixo estão listadas as atividades e códigos presentes nesta seção:

* **`13_area_trapezio.c`** - Programa para calcular a área de um trapézio a partir da base maior, base menor e altura.
* **`extra_par_impar.c`** - Algoritmo que lê uma sequência de números e conta quantos são pares e quantos são ímpares.
* **`1_soma_e_contador.c`** - Programa que realiza a soma sucessiva de números digitados pelo usuário até que o valor zero seja inserido.
* **`2_soma_positivos.c`** - Algoritmo que lê 4 números e soma apenas aqueles que são positivos.
* **`3_soma_1_a_10.c`** - Programa simples utilizando laço de repetição para somar os números de 1 a 10.
* **`4_media_positivos.c`** - Algoritmo que lê 10 números, filtra os positivos, calcula e exibe a média aritmética deles.
* **`5_positivo_negativo_zero.c`** - Programa que classifica uma sequência de números inseridos pelo usuário em positivos, negativos ou zeros.
